Completed my Week 1 project on Cybersecurity and Penetration Testing Lab Setup.

For this project, I set up a virtual cybersecurity lab using Oracle VirtualBox and Kali Linux to create an environment for practical cybersecurity testing.

The main tasks included:
- Installing and configuring Oracle VirtualBox.
- Setting up a Kali Linux virtual machine.
- Configuring the NAT network.
- Setting up network configurations and IP addressing.
- Testing network connectivity and internet access.
- Creating a virtual machine snapshot for future use.

I also documented the setup process and configurations with screenshots and uploaded the project documentation to GitHub.
